# NetLedger

NetLedger is an IT network inventory dashboard for tracking devices, IP addresses, owners, warranty dates, status, and notes.

## Run

```sh
python3 server.py
```

Open `http://127.0.0.1:8108`.

## What it demonstrates

- IT asset tracking
- IP address validation
- SQLite inventory database
- Status and incident notes
- Local HTTP and domain tests

This is an inventory demo, not a network scanner.
